\# Changelog



All notable changes to this project are listed here.



\## \[Unreleased]

\### Added

\- GitHub Actions CI for backend tests and frontend tests/build

\- Pull request and issue templates, Dependabot, contributing guide



\## \[0.2.0]

\### Added

\- Light violet frontend redesign and Vercel config

\- Backend hosting on Render with Neon Postgres



\## \[0.1.0] – First MVP

\### Added

\- Safe ZIP ingestion with malicious-archive tests

\- File scanning, language detection, dependency manifests and framework detection

\- Tree-sitter relationships for JS/TS (imports, Express routes, Mongoose models)

\- Report assembly and persistence (JSONB)

\- Evidence-grounded LLM summaries with secret redaction and citation validation

\- Accounts, private projects and learning features
